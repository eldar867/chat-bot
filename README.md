# Telegram Bot: Погода и Новости

Чат-бот для Telegram с функциями получения погоды и новостей.

## Функционал
- Погода в реальном времени (через OpenWeatherMap API)
- Новости (заглушка для будущей интеграции)
- Информация о боте
- Интерактивные inline-кнопки

## Технологии
- Python 3.10+
- aiogram 3.x (асинхронный фреймворк)
- aiohttp (HTTP-запросы)
- python-dotenv (управление конфигурацией)
